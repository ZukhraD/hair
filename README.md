# Укладка по шагам

Прототип сайта с пошаговыми уроками укладки: утюжок, плойка, брашинг, Dyson Airwrap i.d. (HS08) и Co-anda2x (HS09).
Уроки подстраиваются под тип, густоту и длину волос.

Сайт статический: один файл `index.html`, без сборки.

## Публикация на Vercel
1. Загрузите эту папку в новый репозиторий на GitHub.
2. На vercel.com: Add New → Project → выберите репозиторий → Deploy.
   Framework Preset: Other, Build Command: пусто.
3. Каждое изменение в репозитории будет автоматически публиковаться.
